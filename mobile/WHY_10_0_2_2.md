# 为什么 Android 模拟器使用 10.0.2.2？

## 原因

### Android 模拟器的网络架构

Android 模拟器运行在一个**独立的虚拟网络环境**中：

```
┌─────────────────────────────────────┐
│  Android 模拟器（虚拟设备）          │
│  ┌───────────────────────────────┐   │
│  │  localhost / 127.0.0.1        │   │ ← 指向模拟器自身
│  │  10.0.2.1                     │   │ ← 模拟器的网关
│  │  10.0.2.2                     │   │ ← 宿主机的 localhost ✨
│  │  10.0.2.3                     │   │ ← 宿主机的 DNS 服务器
│  └───────────────────────────────┘   │
└─────────────────────────────────────┘
              ↓ 网络桥接
┌─────────────────────────────────────┐
│  宿主机（你的电脑）                  │
│  localhost:4000 (后端服务)          │
└─────────────────────────────────────┘
```

### 为什么不能用 localhost？

在 Android 模拟器中：
- `localhost` 或 `127.0.0.1` → 指向**模拟器自身**，不是你的电脑
- 如果使用 `localhost:4000`，模拟器会在自己内部查找服务，找不到后端

### 为什么是 10.0.2.2？

这是 **Android 模拟器的特殊网络配置**：

| IP 地址 | 含义 |
|---------|------|
| `10.0.2.1` | 模拟器的路由器/网关 |
| `10.0.2.2` | **宿主机的 localhost** ✨ |
| `10.0.2.3` | 宿主机的 DNS 服务器 |
| `10.0.2.4` | 宿主机的第一个 DNS 服务器（备用） |

所以：
- Android 模拟器访问 `10.0.2.2:4000` → 实际访问宿主机的 `localhost:4000`

## 对比不同平台

### Android 模拟器
```env
API_BASE_URL=http://10.0.2.2:4000
```
- ❌ 不能用 `localhost`（指向模拟器自身）
- ✅ 必须用 `10.0.2.2`（指向宿主机）

### iOS 模拟器
```env
API_BASE_URL=http://localhost:4000
```
- ✅ 可以直接用 `localhost`（iOS 模拟器共享宿主机的网络）

### 真机（Android/iOS）
```env
API_BASE_URL=http://192.168.1.100:4000
```
- ❌ 不能用 `localhost`（指向手机自身）
- ❌ 不能用 `10.0.2.2`（这是模拟器专用）
- ✅ 必须用电脑的实际 IP 地址

## 代码中的自动处理

项目代码已经自动处理了这个问题（`mobile/src/config/api.ts`）：

```typescript
if (Platform.OS === 'android') {
  // Android 模拟器需要使用 10.0.2.2 访问宿主机
  return 'http://10.0.2.2:4000';
} else if (Platform.OS === 'ios') {
  // iOS 模拟器可以使用 localhost
  return 'http://localhost:4000';
}
```

## 替代方案：adb 端口转发

如果 `10.0.2.2` 不工作（比如 WSL 网络问题），可以使用 `adb reverse`：

```bash
# 将模拟器的 4000 端口转发到宿主机
adb reverse tcp:4000 tcp:4000

# 然后使用 localhost
API_BASE_URL=http://localhost:4000
```

这样：
- 模拟器访问 `localhost:4000` → adb 转发 → 宿主机 `localhost:4000`

## 总结

- **Android 模拟器**：使用 `10.0.2.2` 是因为模拟器的网络隔离
- **iOS 模拟器**：可以直接用 `localhost`（网络共享）
- **真机**：必须用电脑的实际 IP 地址

这是 Android 模拟器的**设计特性**，不是 bug！

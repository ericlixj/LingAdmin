# 离线使用说明

## 当前应用状态

你的应用当前**需要网络连接**才能正常工作，因为：

1. **所有数据都来自后端 API**：
   - 登录/注册需要连接后端
   - 传单详情、加油站、邮编等数据都通过 API 获取
   - 没有实现本地数据缓存

2. **应用已经"部署"到手机上**：
   - 如果使用的是**生产构建**（通过 EAS Build 或 Xcode 构建），应用已经安装在手机上
   - 如果使用的是**Expo Go**，应用代码在手机上，但仍然需要连接开发服务器

## 部署方式对比

### 1. Expo Go（开发模式）
- ✅ 应用代码在手机上
- ❌ **需要连接开发服务器**（Metro bundler）
- ❌ **不能离线使用**
- ✅ 适合快速开发和测试

### 2. 开发构建（Development Build）
- ✅ 应用已安装在手机上
- ❌ **需要连接开发服务器**（热重载功能）
- ❌ **不能完全离线**（需要网络获取最新代码）
- ✅ 适合开发测试

### 3. 生产构建（Production Build）
- ✅ 应用已安装在手机上
- ✅ 代码已打包在应用中
- ⚠️ **仍然需要网络连接**才能访问 API
- ✅ 可以离线查看已缓存的数据（如果有实现）

## 离线使用的限制

### 当前限制

1. **登录/认证**：需要网络连接到后端服务器
2. **数据获取**：所有数据（传单、加油站、邮编）都需要 API 请求
3. **没有数据缓存**：应用关闭后数据不会保存

### 如果要实现离线使用

需要实现以下功能：

1. **数据缓存**：
   - 将 API 返回的数据保存到 AsyncStorage 或本地数据库
   - 应用启动时先从缓存加载数据
   - 网络可用时同步最新数据

2. **离线模式检测**：
   - 检测网络连接状态
   - 网络不可用时显示缓存数据
   - 提示用户当前为离线模式

3. **数据同步**：
   - 网络恢复时自动同步
   - 处理数据冲突

## 当前推荐的使用方式

### 开发阶段
- 使用 **Expo Go** 或 **开发构建**
- 需要保持开发服务器运行
- 需要网络连接

### 测试阶段
- 使用 **生产构建**（EAS Build 或本地构建）
- 应用已安装在手机上
- 仍然需要网络连接访问 API

### 生产使用
- 使用 **生产构建**
- 应用安装在用户手机上
- **需要网络连接**才能使用所有功能

## 如何部署到手机（生产构建）

### 方法 1：EAS Build（推荐）

```bash
cd mobile
npm run ios:build
# 或
npm run android:build:production
```

构建完成后，下载并安装到手机。

### 方法 2：本地 Xcode 构建（iOS）

```bash
cd mobile
npm run ios -- --device
```

或使用我们创建的脚本：
```bash
./deploy-ios-production.sh
```

### 方法 3：本地 Android 构建

```bash
cd mobile
npm run android
```

## 总结

- ✅ **应用已经可以"部署"到手机上**（生产构建）
- ⚠️ **但仍需要网络连接**才能使用（访问 API）
- ❌ **目前不支持真正的离线使用**（没有数据缓存）
- 💡 **如果需要离线功能**，需要实现数据缓存和同步机制

## 是否需要实现离线功能？

如果你的需求是：
- ✅ 应用安装在手机上即可（已满足）
- ✅ 有网络时可以正常使用（已满足）
- ❌ 完全离线使用（需要额外开发）

如果确实需要离线功能，我可以帮你实现数据缓存功能。

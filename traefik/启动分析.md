# Traefik 启动流程分析

## 📁 文件结构

```
traefik/
├── docker-compose.traefik.yml    # Traefik 主配置文件
├── config_env_staging.sh         # 预生产环境变量配置
├── config_env_test.sh            # 测试环境变量配置
└── config_env_production.sh      # 生产环境变量配置
```

## 🚀 启动流程

### 1. 前置准备

#### 1.1 创建 Docker 网络

Traefik 需要一个名为 `traefik-public` 的外部网络来与其他服务通信：

```bash
docker network create traefik-public
```

**注意**：这个网络必须在启动 Traefik 之前创建，因为 `docker-compose.traefik.yml` 中声明它为 `external: true`。

#### 1.2 设置环境变量

根据部署环境选择对应的配置文件：

**预生产环境 (Staging):**
```bash
source traefik/config_env_staging.sh
```

**测试环境 (Test):**
```bash
source traefik/config_env_test.sh
```

**生产环境 (Production):**
```bash
source traefik/config_env_production.sh
```

这些脚本会设置以下环境变量：
- `USERNAME`: Traefik Dashboard 的 HTTP Basic Auth 用户名
- `PASSWORD`: 原始密码（用于生成哈希）
- `HASHED_PASSWORD`: 使用 `openssl passwd -apr1` 生成的哈希密码
- `DOMAIN`: 主域名（如 `kxf.ca`, `dw.cacnaturals.ca`）
- `EMAIL`: Let's Encrypt 证书申请邮箱

### 2. 启动 Traefik

进入 traefik 目录并启动：

```bash
cd traefik
docker compose -f docker-compose.traefik.yml up -d
```

或者从项目根目录：

```bash
docker compose -f traefik/docker-compose.traefik.yml up -d
```

### 3. 配置说明

#### 3.1 端口映射

- **80**: HTTP 入口，用于重定向到 HTTPS
- **443**: HTTPS 入口，主要服务端口

#### 3.2 核心功能

1. **Docker Provider**: 自动发现并配置 Docker 容器服务
   - `--providers.docker`: 启用 Docker provider
   - `--providers.docker.exposedbydefault=false`: 只暴露明确标记的服务

2. **入口点 (Entrypoints)**:
   - `http`: 监听 80 端口
   - `https`: 监听 443 端口

3. **SSL/TLS 证书**:
   - 使用 Let's Encrypt 自动申请证书
   - 证书存储位置: `/certificates/acme.json` (挂载到 volume)
   - 证书解析器: `le` (Let's Encrypt)
   - 使用 TLS Challenge 验证域名所有权

4. **Dashboard**:
   - 访问地址: `https://traefik.${DOMAIN}`
   - 启用 HTTP Basic Auth 保护
   - 使用 `api@internal` 服务

5. **中间件**:
   - `https-redirect`: 自动将 HTTP 请求重定向到 HTTPS
   - `admin-auth`: Dashboard 的 HTTP Basic Auth 认证

#### 3.3 数据持久化

- **Volume**: `traefik-public-certificates`
  - 存储 Let's Encrypt 证书
  - 即使容器重建，证书也不会丢失

- **Docker Socket**: `/var/run/docker.sock`
  - 只读挂载，用于读取其他容器的标签配置

## 🔗 与其他服务集成

### 主应用服务配置

在 `docker-compose.yml` 中，所有需要暴露的服务都：
1. 加入 `traefik-public` 网络
2. 添加 Traefik labels 配置路由规则

**示例服务路由**:
- `api.${DOMAIN}` → `admin-backend` (端口 8000)
- `dashboard.${DOMAIN}` → `admin-frontend` (端口 80)
- `c-api.${DOMAIN}` → `capp-backend` (端口 4000)
- `c.${DOMAIN}` → `capp-frontend` (端口 80)
- `adminer.${DOMAIN}` → `adminer` (端口 8080)
- `opensearch.${DOMAIN}` → `opensearch-dashboards` (端口 5601)
- `traefik.${DOMAIN}` → Traefik Dashboard (端口 8080)

### Traefik Labels 说明

每个服务需要的关键 labels：

```yaml
labels:
  # 启用 Traefik
  - traefik.enable=true
  # 指定网络
  - traefik.docker.network=traefik-public
  # 服务端口
  - traefik.http.services.${STACK_NAME}-service.loadbalancer.server.port=8000
  # HTTP 路由规则
  - traefik.http.routers.${STACK_NAME}-service-http.rule=Host(`api.${DOMAIN}`)
  - traefik.http.routers.${STACK_NAME}-service-http.entrypoints=http
  - traefik.http.routers.${STACK_NAME}-service-http.middlewares=https-redirect
  # HTTPS 路由规则
  - traefik.http.routers.${STACK_NAME}-service-https.rule=Host(`api.${DOMAIN}`)
  - traefik.http.routers.${STACK_NAME}-service-https.entrypoints=https
  - traefik.http.routers.${STACK_NAME}-service-https.tls=true
  - traefik.http.routers.${STACK_NAME}-service-https.tls.certresolver=le
```

## 🛠️ 本地开发环境

在本地开发时，使用 `docker-compose.override.yml` 中的 `proxy` 服务：

- 使用相同的 Traefik 镜像
- 启用 `--api.insecure=true` 允许不安全访问 Dashboard
- Dashboard 可通过 `http://localhost:8090` 访问
- 不启用 HTTPS 和 Let's Encrypt（本地开发不需要）

## 📋 完整启动命令示例

### 生产环境启动流程

```bash
# 1. 创建网络（如果不存在）
docker network create traefik-public

# 2. 设置环境变量
source traefik/config_env_production.sh

# 3. 启动 Traefik
cd traefik
docker compose -f docker-compose.traefik.yml up -d

# 4. 验证启动
docker compose -f docker-compose.traefik.yml ps
docker compose -f docker-compose.traefik.yml logs -f
```

### 检查 Traefik 状态

```bash
# 查看容器状态
docker ps | grep traefik

# 查看日志
docker compose -f traefik/docker-compose.traefik.yml logs -f

# 访问 Dashboard（需要认证）
# https://traefik.${DOMAIN}
```

## ⚠️ 注意事项

1. **网络必须先创建**: `traefik-public` 网络必须在启动 Traefik 之前存在
2. **环境变量必须设置**: 所有必需的环境变量（`DOMAIN`, `EMAIL`, `USERNAME`, `HASHED_PASSWORD`）必须在启动前设置
3. **域名解析**: 确保所有子域名（`api.${DOMAIN}`, `dashboard.${DOMAIN}` 等）都正确解析到服务器 IP
4. **防火墙**: 确保 80 和 443 端口对外开放，Let's Encrypt 需要访问这些端口进行验证
5. **证书申请**: 首次启动时，Let's Encrypt 证书申请可能需要几分钟时间
